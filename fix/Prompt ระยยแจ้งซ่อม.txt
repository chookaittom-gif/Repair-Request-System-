==================================================
LOADING UX RULE
==================================================

ต้องยึดกฎนี้ด้วยถ้ามีการแตะจุดโหลดเดือนรายงาน

- ถ้าข้อมูลโหลดเกิน 300ms ต้องแสดง loading state
- ถ้าเป็นข้อมูลใหญ่ เช่น ปฏิทิน, ตาราง, ประวัติ, dashboard ต้องมี loading message ชัดเจน
- ต้องบอกผู้ใช้ว่ากำลังโหลดข้อมูลอะไร
- ห้ามปล่อยหน้าว่างโดยไม่มีสถานะ
- action ที่เกี่ยวข้องต้อง disabled ระหว่างโหลด
- ถ้าโหลดไม่สำเร็จต้องมี error state และ retry ได้
- loading บนมือถือ ต้องเห็นชัดและไม่ทำให้ layout กระตุก

สำหรับจุดนี้
- ถ้ากำลังโหลดเดือนรายงาน ให้แสดงข้อความเช่น “กำลังโหลดเดือนรายงาน...”
- select เดือนและปุ่มที่เกี่ยวข้องต้อง disabled ระหว่างโหลด
- ถ้าโหลดเดือนไม่สำเร็จ ต้องมีข้อความ error และปุ่ม retry
