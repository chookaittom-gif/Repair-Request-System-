คุณคือ Senior Google Apps Script Developer

แก้ Production แบบ Minimal Change เท่านั้น

## Problem

งานแจ้งซ่อมที่สร้างใหม่บางรายการมีสถานะเป็นค่าว่างหรือ `-`

ทำให้:

* Modal อัปเดตงานซ่อมแสดงสถานะเป็น `-`
* Dashboard นับสถานะผิด
* ตารางรายการแจ้งซ่อมแสดงสถานะไม่ชัดเจน
* ประวัติงานไม่สมบูรณ์

ต้องการให้ทุกงานแจ้งซ่อมใหม่มีสถานะเริ่มต้นเป็น:

```text
รอดำเนินการ
```

ตั้งแต่บันทึกครั้งแรก

---

## Scope

ตรวจและแก้เฉพาะไฟล์ที่เกี่ยวข้องกับการสร้างใบแจ้งซ่อมและแสดงสถานะ:

```text
Code.gs
index.txt
dashboard.txt
```

ถ้ามีชื่อไฟล์จริงต่างกัน ให้ใช้ไฟล์ที่มีฟังก์ชันรับฟอร์มแจ้งซ่อม

ห้ามแก้:

```text
stockController.gs
stock.txt
Schema
Sheet Structure
Business Logic อื่น
```

---

## Required Fix

### 1. Backend: ตั้งค่า Status ตอนสร้างงานใหม่

ค้นหาฟังก์ชันที่รับฟอร์มแจ้งซ่อม เช่น:

```text
submitForm
submitRepairRequest
saveRepairRequest
createRepairRequest
```

ตอน append row ลง Sheet `รายการแจ้งซ่อมทั้งหมด`

ให้กำหนดค่า status เป็น:

```js
'รอดำเนินการ'
```

ถ้า object form ไม่มี status หรือ status ว่าง ให้ fallback:

```js
var initialStatus = String(formData.status || '').trim() || 'รอดำเนินการ';
```

แต่ถ้าเป็นการสร้างงานใหม่ ให้ใช้ `รอดำเนินการ` เสมอ

---

### 2. Backend: ถ้ามีคอลัมน์สถานะล่าสุด

ถ้า Sheet มีคอลัมน์:

```text
สถานะ
สถานะล่าสุด
```

ให้เขียนค่าเริ่มต้นเป็น:

```text
รอดำเนินการ
```

ทั้งสองจุดที่เกี่ยวข้อง

ห้ามปล่อยเป็น:

```text
-
''
null
undefined
```

---

### 3. ประวัติสถานะงาน

ถ้ามีการสร้างประวัติสถานะตอนสร้างงานใหม่ ให้เพิ่ม record แรกเป็น:

```text
สร้างใบแจ้งซ่อม
สถานะ: รอดำเนินการ
```

ถ้ายังไม่มีระบบเขียน history ตอนสร้างงาน และต้องเพิ่มโค้ดเยอะ ให้ไม่ต้องเพิ่ม เพื่อคง Minimal Change

แต่ถ้ามี function เดิม เช่น:

```text
addStatusHistory
appendStatusHistory
saveStatusHistory
```

ให้ reuse function เดิมเท่านั้น

---

### 4. Dashboard: Normalize ค่าว่างเก่า

เพื่อรองรับข้อมูลเก่าที่เคยเป็นว่างหรือ `-`

ในฟังก์ชันที่อ่านสถานะ เช่น:

```text
getDashboardData
normalizeStatusName_
renderStatusBadge
processChartData
```

ให้ map ค่าเหล่านี้เป็น:

```text
รอดำเนินการ
```

เฉพาะตอนแสดงผลและนับ Dashboard เท่านั้น:

```js
''
'-'
null
undefined
```

ห้ามแก้ข้อมูลย้อนหลังใน Sheet

---

### 5. Frontend: Modal อัปเดตงานซ่อม

ใน `dashboard.txt`

เมื่อเปิด Modal ถ้าสถานะที่ได้รับมาเป็นค่าว่างหรือ `-`

ให้แสดงและเลือก Pill:

```text
รอดำเนินการ
```

และให้ `#editStatus.value` เป็น:

```text
รอดำเนินการ
```

---

* ห้ามแก้ flow เบิกอะไหล่
* ห้ามแก้ระบบอนุมัติพัสดุ
* ห้ามเปลี่ยนชื่อสถานะอื่น

ตอบกลับเป็น Patch เท่านั้น

```text
File:
Position:
Anchor:
```

ใช้รูปแบบ:

```js
FIND:
...

REPLACE WITH:
...
```

หรือ

```js
INSERT AFTER:
...

CODE TO INSERT:
...
```

## Verify

* สร้างใบแจ้งซ่อมใหม่แล้ว Sheet ได้สถานะ `รอดำเนินการ`
* Modal แสดงสถานะ `รอดำเนินการ`
* Status Pill `รอดำเนินการ` ถูกเลือก
* Dashboard Card `รอดำเนินการ` นับถูกต้อง
* Chart นับถูกต้อง
* ข้อมูลเก่าที่สถานะว่างหรือ `-` แสดงเป็น `รอดำเนินการ`
* ไม่มีผลกับสถานะ `กำลังดำเนินการ`
* ไม่มีผลกับสถานะ `รออะไหล่`
* ไม่มีผลกับระบบเบิกอะไหล่
* ไม่มี Console Error
